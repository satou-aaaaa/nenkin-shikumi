# nenkin-shikumi

年金のしくみ：人の場面から、国民年金の第何号か・保険料の払い方・入る年金を当てる学習ゲーム。

遊ぶ：<https://satou-aaaaa.github.io/nenkin-shikumi/>

- 学生・会社員・自営業・会社員の配偶者・パートなど、架空の人の場面が出ます。まず「第1号・第2号・第3号」のどれかを選び、正解したら「保険料の払い方」「入る年金」「届け出の先」「合う制度（学生納付特例・免除・納付猶予など）」のどれかを選びます。
- 今日の5問（だれでも同じ・1日1回）・上級・練習・とことん（まちがえても続く）・しくみ帳・実績・カレンダー。時間制限はありません。
- 中身は日本年金機構のページで確かめたことだけです。出典は画面の「なぜ」と「このゲームについて」にあります。保険料や年金の金額は年ごとに変わるので、答えにしません。

このゲームは年金の相談ではありません。公式の情報の代わりではありません。自分の年金のことは、年金事務所やねんきんダイヤル（日本年金機構）に相談してください。

- 年金事務所：<https://www.nenkin.go.jp/section/soudan/index.html>
- ねんきんダイヤル：<https://www.nenkin.go.jp/section/tel/toiawase_ippan.html>
